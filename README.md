# Lab 9 Report

During the filming process, it appeared that we did not capture audio. Instead of retaking the three 10-second clips, I decided to convert the project into a silent movie in the style of an old Western.

To accomplish this, I used an adjustment layer and added a monochrome filter. I also used a colour correction tool to reduce the red shadow, blue power, and green shadow to sharpen the contrast between objects. This reduced the overall lighting of the video, but I liked the way it looked, so I kept it.

I gathered still frames for the text, implemented them throughout the video, and added captions. For the music, I used a non-copyrighted sound.
